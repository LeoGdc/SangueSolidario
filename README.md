# 🩸 Sangue Solidário

**Sangue Solidário** é um projeto acadêmico desenvolvido com o objetivo de facilitar o acesso à informação e aproximar pessoas interessadas em doar sangue dos serviços de hemoterapia.

A proposta é criar uma plataforma simples e acessível para auxiliar pessoas que desejam realizar uma doação, reunindo informações importantes em um único ambiente.

## 📌 Sobre o projeto

A doação de sangue é fundamental para o funcionamento dos serviços de saúde. O Sangue Solidário surgiu com a proposta de utilizar a tecnologia para facilitar a comunicação entre potenciais doadores, hemocentros e campanhas de doação.

A plataforma busca tornar o processo mais simples, permitindo que o usuário encontre informações importantes sem precisar procurar em diferentes canais.

## 🎯 Objetivo

O principal objetivo do projeto é **facilitar o processo de busca e acesso à informação sobre doação de sangue**, aproximando potenciais doadores dos hemocentros e campanhas.

### Objetivos específicos

* 📍 Facilitar a localização de hemocentros;
* 🏥 Apresentar informações sobre os locais de doação;
* 🩸 Divulgar campanhas de doação;
* 📋 Informar os requisitos básicos para doação;
* 📅 Facilitar o acesso a informações sobre agendamento;
* 🔔 Incentivar a regularidade das doações;
* 📢 Melhorar a comunicação entre doadores e serviços de hemoterapia;
* ❤️ Incentivar a cultura de doação voluntária.

## 💡 Problema

Muitas pessoas possuem interesse em doar sangue, mas podem encontrar dificuldades para descobrir:

* Onde realizar a doação;
* Quais são os requisitos necessários;
* Como funciona o processo;
* Quais são os horários de atendimento;
* Se é necessário realizar agendamento;
* Onde existem campanhas de doação;
* Quando poderão realizar uma nova doação.

O Sangue Solidário busca reduzir essas dificuldades por meio de uma plataforma centralizada e de fácil utilização.

## 🚀 Proposta da solução

O Sangue Solidário pretende reunir informações relacionadas à doação de sangue em um único ambiente.

A plataforma conecta:

**👤 Doador → 🩸 Sangue Solidário → 🏥 Hemocentro**

Dessa forma, o usuário poderá encontrar informações sobre locais de doação, campanhas e orientações necessárias para realizar o procedimento.

## 🛠️ Funcionalidades

### Para o doador

* Cadastro de usuário;
* Consulta de informações sobre doação;
* Busca por hemocentros;
* Visualização de campanhas;
* Consulta de requisitos para doação;
* Informações sobre horários e atendimento;
* Histórico de doações;
* Lembretes para futuras doações.

### Para hemocentros

* Cadastro da unidade;
* Divulgação de campanhas;
* Informações de funcionamento;
* Divulgação de necessidades;
* Gerenciamento das informações disponibilizadas aos usuários.

> Algumas funcionalidades poderão depender de futuras integrações com sistemas oficiais e das regras aplicáveis aos serviços de hemoterapia.

## 🔐 Privacidade e segurança

Por trabalhar com informações relacionadas à saúde e dados pessoais, o projeto considera a importância de:

* Proteção dos dados dos usuários;
* Controle de acesso;
* Autenticação;
* Segurança das informações;
* Princípios da LGPD;
* Utilização responsável dos dados.

O projeto não pretende substituir sistemas oficiais de saúde ou determinar a aptidão médica de uma pessoa para realizar uma doação.
